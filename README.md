# Countries Search App

## Overview

The Countries Search App is a simple and responsive web application that allows users to search for countries and view their population details along with national flags.

## Features

* Fetches live country data from API
* Real-time country search
* Displays country flag, name, and population
* Responsive UI using Bootstrap
* Loading spinner while fetching data

## Technologies Used

* HTML5
* CSS3
* Bootstrap
* JavaScript

## How It Works

1. Fetches country data from the API.
2. Displays all countries initially.
3. Filters countries dynamically based on user input.
4. Updates results instantly during typing.
